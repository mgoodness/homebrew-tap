## How do I install these formulae?

`brew install mgoodness/tap/<formula>`

Or `brew tap mgoodness/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "mgoodness/tap"
brew "<formula>"
```
